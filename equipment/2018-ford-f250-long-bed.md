# 2018 Ford F-250 Long-Bed Baseline

Status: **cab and actual dimensions unverified**

Overall length varies by cab, so `F-250 long bed` is not sufficient for a scaled plan.

| 8-ft box configuration | Published overall length |
|---|---:|
| Regular Cab | 231.8 in / 19.32 ft |
| SuperCab | 254.4 in / 21.20 ft |
| Crew Cab | 266.2 in / 22.18 ft |

A Crew Cab long-bed wheelbase is published at approximately 176 in. Aftermarket bumpers, steps, mirrors, hitch equipment, and tires can change the working envelope.
