How this works

  • Use the zoom slider, −/+ buttons, Fit plan, or Fit aerial context. Zooming out reveals the surrounding campground while dragging remains measured in local feet.
  • Drag a pass by clicking and dragging its shape.
  • Click a pass (on the canvas or in the list) to select it, then fine-tune with the X/Y/rotation fields.
  • Positions are the pass SVG's own top-left corner (each file has a small margin around its true 600 sq ft boundary — see maps/overlays/passes/passes-manifest.json).
  • Layout autosaves to this browser's local storage. Use Save/Load to keep a portable copy in the repo or share it.
  • Each pass file under maps/overlays/passes/ can be edited independently, then regenerate with python scripts/build_pass_svgs.py (or hand-edit the SVGs directly) — reload this page to pick up changes.
  • The muted aerial backdrop is a committed local copy of Texas NAIP 2022 (60 cm) imagery, so the layout tool no longer waits on a live GIS service. Its roughly 700 × 450 ft extent provides surrounding road, clearing, and tree context while the editable planning coordinates remain the same 230 × 200 ft area. The image is affine-warped in the browser using the same local-foot/WGS84 transform as group-site-v0.1.geojson, correcting the former ~1.68° rotation and the resulting southern-road drift. This is still planning imagery, not a survey.
  • The cyan line through 30°15'20.86"N 95°50'47.36"W and 30°15'19.63"N 95°50'47.44"W is a hard western limit. Passes are automatically kept east of its extrapolated alignment, including when rotated or loaded from an older saved layout.
