# TRF Site Planning Overview

Planning repository for a Texas Renaissance Festival campsite submission and field setup.

## Current design intent

- Planning target: **up to 600 sq ft**, pending written confirmation from TRF.
- Camper: believed to be a **2012 Forest River Wildcat Sterling Edition 29MK**; model and field dimensions still need confirmation.
- Camper orientation: hitch/nose facing **south**.
- Entry door: facing **west**, away from the road.
- Working road assumption: road lies along the **east** side of the plot.
- Canopy: positioned along the south edge near the southwest corner, with its long dimension perpendicular to the camper.
- Power: two Cummins Onan P4500i portable inverter generators.
- Screening: temporary freestanding visual boundary near the camper's front/south end to reduce generator visibility without enclosing the generators or obstructing cooling/exhaust.

## Drawing rules

Every drawing intended for review or field use should show:

1. Source date and revision.
2. North arrow.
3. Explicit scale and a scale bar.
4. Overall plot dimensions and calculated area.
5. Road edge and required roadway setback.
6. Camper body plus each slide, stair, awning, hitch, and utility projection.
7. Canopy, fence/screening, generators, fuel, vehicle, paths, and emergency exit route.
8. Dimensions between all safety-critical objects.
9. A clear distinction between verified measurements and estimates.

## Critical unresolved feasibility question

Portable-generator guidance generally calls for substantial separation from doors, windows, vents, and occupied structures. The generator location must be proven safe using actual camper openings and plot boundaries before the fence or final layout is approved. A visual screen must not become a generator enclosure.
