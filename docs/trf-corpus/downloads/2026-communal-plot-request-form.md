## Communal / Guild Land Request Overview

- Alternative request workflow for group campsites, clans, and guilds.
- Requires designated Clan/Guild leader contact information.
- Aggregates multiple season pass holders into a unified site footprint.
- Must provide map boundary drawing and equipment inventory matching the aggregate square footage limit.
