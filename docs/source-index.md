# Source Index

Last reviewed: **2026-07-27**

Use sources in this order:

1. Current TRF forms, rules, approvals, and written site-specific guidance.
2. Manufacturer manuals, labels, and specifications.
3. Government safety, terrain, soil, flood, and environmental data.
4. Reputable secondary specification databases.
5. Scale-derived estimates, clearly marked as estimates.

## Evidence-handling rule

For every final-plan measurement, record:

- value and unit;
- object and endpoints;
- source URL, document, photograph, or field record;
- date obtained;
- confidence: `verified-field`, `verified-document`, `published`, `scale-derived`, or `assumed`;
- verifier, when applicable.
